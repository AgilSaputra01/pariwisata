# 43. SEO Automation

Admin SEO memiliki dua lapisan.

## Automatic SEO

System mengambil:

```text
Service Name
Destination
Route
Description
FAQ
```

dan menghasilkan:

```text
Title
Description
OG
Schema
Breadcrumb
Internal Links
```

## Manual Override

Admin dapat mengganti:

```text
SEO title
Meta description
Canonical
OG image
Index/noindex
Schema configuration
```

Prioritas:

```text
Manual SEO
    ↓
Automatic SEO
```

---

# 44. AI-Assisted Content

Tahap berikutnya dapat ditambahkan AI untuk membantu admin:

```text
Generate SEO title
Generate meta description
Generate FAQ
Generate travel article
Generate service description
Suggest internal links
SEO content audit
```

AI tidak boleh otomatis menerbitkan konten tanpa moderation admin.
