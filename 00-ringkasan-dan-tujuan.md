# 1. Ringkasan Proyek

Project ini merupakan platform website layanan transportasi pariwisata yang berfokus pada **mobil rental/transportasi dan fastboat**.

Tujuan utama platform adalah mempermudah wisatawan dan pencari layanan transportasi untuk:

- menemukan layanan mobil;
- menemukan layanan fastboat;
- melihat detail layanan;
- mengetahui harga dan fasilitas;
- melihat rute;
- melihat jadwal;
- melakukan booking;
- berkomunikasi dengan operator melalui WhatsApp;
- mendapatkan informasi perjalanan melalui website yang cepat dan mudah ditemukan di Google.

Platform dirancang menggunakan:

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **WhatsApp Gateway / WhatsApp JS**
- **SEO Architecture**
- **Database**
- **Admin Dashboard**
- **REST API / Server Actions**
- **Image Optimization**
- **Structured Data**
- **Responsive Mobile-First UI**

Website harus diposisikan bukan sekadar sebagai landing page, tetapi sebagai **platform discovery + booking transportasi wisata**.

---

# 2. Tujuan Utama

## 2.1 Tujuan Bisnis

Membangun website yang mampu menjadi sumber utama calon pelanggan ketika mencari:

- rental mobil Bali;
- sewa mobil Bali;
- transportasi bandara Bali;
- private car Bali;
- fastboat Bali;
- fastboat Bali ke Nusa Penida;
- fastboat Bali ke Nusa Lembongan;
- fastboat Sanur;
- fastboat Padang Bai;
- tiket fastboat Bali;
- transportasi wisata Bali;
- paket transportasi wisata.

Website harus mengubah trafik organik menjadi **lead dan booking melalui WhatsApp**.

---

# 3. Target Pengguna

## 3.1 Wisatawan Lokal

Pengguna dari Indonesia yang membutuhkan:

- rental mobil;
- antar-jemput bandara;
- transportasi antar kota;
- fastboat;
- transportasi menuju destinasi wisata.

## 3.2 Wisatawan Internasional

Website harus mendukung bahasa:

- Bahasa Indonesia;
- English.

Struktur multilingual harus SEO-friendly.

Contoh:

```text
/id/
    rental-mobil-bali/
    fastboat-bali/
    booking/

/en/
    bali-car-rental/
    bali-fastboat/
    booking/
```
