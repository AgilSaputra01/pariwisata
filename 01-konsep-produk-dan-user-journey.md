# 4. Konsep Produk

Platform terdiri dari dua kategori layanan utama.

## 4.1 Car / Transport

Contoh layanan:

- Airport Transfer
- Car Rental
- Private Driver
- Bali Tour Transport
- Intercity Transfer
- Hotel Transfer
- Custom Transportation

## 4.2 Fastboat

Contoh:

- Sanur → Nusa Penida
- Sanur → Nusa Lembongan
- Padang Bai → Gili Trawangan
- Padang Bai → Gili Air
- Padang Bai → Lombok
- Bali → Nusa Penida
- Bali → Nusa Lembongan

Rute harus dapat dikelola melalui admin.

# 5. User Journey

## 5.1 Discovery

User melakukan pencarian di Google.

Contoh:

```text
fastboat sanur nusa penida
rental mobil bali murah
sewa mobil bali dengan driver
fastboat bali lombok
```

User masuk ke halaman SEO yang relevan.

## 5.2 Exploration

User dapat:

1. melihat informasi layanan;
2. melihat harga;
3. melihat fasilitas;
4. melihat jadwal;
5. melihat rute;
6. melihat pickup/drop-off;
7. membaca FAQ;
8. melihat review;
9. melihat galeri.

## 5.3 Booking

User menekan:

```text
BOOK NOW
```

Kemudian mengisi:

```text
Nama
Nomor WhatsApp
Tanggal
Jumlah Penumpang
Layanan
Rute
Pickup
Drop-off
Jam
Catatan
```

Setelah submit, sistem membuat booking dan membuka WhatsApp.
