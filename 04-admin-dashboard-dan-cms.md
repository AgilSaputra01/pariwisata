# 8. Admin Dashboard

Admin digunakan untuk mengelola seluruh konten dan operasional.

## 8.1 Dashboard

Menampilkan:

- total booking;
- booking hari ini;
- booking pending;
- booking confirmed;
- revenue;
- layanan populer;
- rute populer;
- traffic summary;
- conversion summary.

## 8.2 Service Management

Admin dapat:

- tambah layanan;
- edit layanan;
- hapus layanan;
- publish/unpublish;
- mengatur harga;
- fasilitas;
- foto;
- deskripsi;
- SEO metadata.

## 8.3 Route Management

Contoh:

```text
Sanur → Nusa Penida
Sanur → Nusa Lembongan
Padang Bai → Gili Trawangan
```

Admin dapat mengatur:

- departure;
- arrival;
- duration;
- schedule;
- price;
- operator;
- active status.

## 8.4 Booking Management

Admin dapat:

- melihat booking;
- mencari booking;
- filter status;
- mengubah status;
- melihat detail pelanggan;
- menghubungi WhatsApp;
- mengirim confirmation;
- membatalkan booking.

---

# 9. CMS

Admin harus dapat mengelola konten tanpa mengubah source code.

CMS meliputi:

- Pages;
- Blog;
- FAQ;
- Destinations;
- Services;
- Routes;
- Operators;
- Reviews;
- Gallery;
- Promotions;
- SEO.
