
```text
New Booking
Booking Confirmed
```

# 31. Analytics

Integrasikan:

- Google Analytics;
- Google Search Console;
- conversion tracking;
- booking tracking;
- WhatsApp click tracking;
- search tracking.

Event contoh:

```text
view_service
view_route
search_transport
start_booking
submit_booking
click_whatsapp
booking_confirmed
```

# 32. Conversion Optimization

Setiap halaman layanan harus memiliki CTA.

Contoh:

```text
Check Availability
Book Now
Chat on WhatsApp
```

CTA harus tersedia:

- hero;
- service detail;
- route detail;
- mobile sticky bar;
- bottom section.
